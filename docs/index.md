## Algo Verify
This repository is by Vinit Ranjan, Jisun Park, Stefano Gualandi, Andrea Lodi, and Bartolomeo Stellato
and contains the Python source code to reproduce experiments in our paper Exact Verification of
First-Order Methods via Mixed-Integer Linear Programming.

Source Code: [https://github.com/stellatogrp/algo_verify](https://github.com/stellatogrp/algo_verify)
